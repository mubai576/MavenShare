5 · 新手引导（首次必看）

  1. 到 central.sonatype.com 注册账号，并在 Namespace 页面验证你的域名，拿到可用的 groupId（如 com.example）。
  2. 在 Portal 右上角生成 User Token，把用户名与密码填到上方表单并点“保存 Token”。
  3. 安装 Gpg4win（官网 gpg4win.org），装完在下方“0 · GPG 安装与密钥”填写姓名邮箱并点“生成密钥”，密钥列表出现即代表就绪（一键安装失败时去官网 gpg4win.org 手动装）。
  4. 回到本工具：选文件 → 填 GAV → 点“校验坐标” → 点“本地试打包”确认 bundle 结构 → 点“发布到中央仓”。
  5. 发布成功后工具会自动追加合集清单并发布 share-catalog 新版本；在“合集清单预览”里可看到放了什么、何时放的；中央仓 release 版本不可覆盖，清单用递增版本号实现“覆盖最新版”体验。
